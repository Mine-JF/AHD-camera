# 手机遥控试用版

同一 Android 工程现在有 `board` 和 `phone` 两种构建变体。主板版应用 ID 保持
`com.example.ahd_camera`，保留系统 UID 和原有主板平台签名；手机版应用 ID 是
`com.example.ahd_camera.phone`，不使用系统 UID。主板版仍从 `Camera_view`
启动；手机版从 `PhoneRemoteActivity` 启动。

主板和手机连接同一个 Wi-Fi。先启动主板应用，在主板端查看 Wi-Fi IP；再启动手机
应用，输入主板 IP 并点击“连接”。手机通过 TCP 39001 发送控制命令，通过 TCP
39002 接收主板预览合成后的 H.264 画面。方向键按下时开始运动，抬起时停止；
对焦按钮每次调整一档。拍照和录像操作仍由主板执行并保存在主板存储设备上。

这是连通性试用版：视频为 640×360、10 fps；尚无设备自动发现、配对认证、
断线重连或录制文件下载。只应在可信的隔离 Wi-Fi 上试用。主板页面在前台时才
提供服务，控制连接断开超过 3 秒会停止电机。
